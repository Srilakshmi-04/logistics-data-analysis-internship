# Logistics Data Analysis Internship

This repository contains the work completed during my Logistics Data Analyst Internship. The project focuses on applying Python and data science techniques to logistics and supply chain problems through a structured four-week workflow.

## Internship Overview

The internship covers strategic planning, data exploration, data preprocessing, exploratory analysis, visualization, predictive modeling, and optimization in logistics systems.

## Week 1 – Strategic Planning and Data Exploration

The first week focused on defining a realistic logistics scenario, identifying relevant Key Performance Indicators (KPIs), conducting background research, and preparing a strategic roadmap for logistics data analysis.

Key areas included:
- Logistics scenario and problem definition
- KPI identification
- Background and data research
- Application of regression, clustering, and optimization concepts
- Strategic analysis roadmap
- Python code illustrations

**Status:** Completed

## Week 2 – Data Collection, Cleaning and Preprocessing

Week 2 focuses on preparing logistics data for further analysis using Python.

The preprocessing workflow includes:
- Data collection simulation
- Dataset inspection
- Data quality assessment
- Missing-value detection and handling
- Duplicate record checking and removal
- Outlier detection using the IQR method
- Numerical data preprocessing
- Min-Max normalization
- Final data validation

Python libraries used:
- Pandas
- Scikit-learn

The Week 2 work includes a Python Jupyter Notebook, an illustrative logistics dataset, and a detailed Word report explaining the methodology and its impact on logistics analytics.

**Status:** Completed

## Week 3 – Advanced Data Analysis and Visualization

Week 3 will focus on exploratory data analysis and visualization of logistics data.

Planned activities:
- Exploratory Data Analysis (EDA)
- Statistical summaries
- Distribution analysis
- Correlation analysis
- Logistics performance visualizations
- Interpretation of operational efficiency and cost drivers
- Identification of potential bottlenecks

**Status:** Upcoming

## Week 4 – Predictive Modeling and Optimization

Week 4 will focus on predictive modeling and optimization in logistics systems.

Planned activities:
- Definition of a logistics forecasting problem
- Data preparation
- Predictive model development
- Model evaluation using metrics such as MAE, RMSE, and R²
- Model validation and tuning
- Logistics optimization strategies
- Resource allocation, route planning, and cost minimization analysis

**Status:** Upcoming
